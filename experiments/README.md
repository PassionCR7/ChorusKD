# 实验脚本

本目录存放 README 中数据性结论的复现脚本。原始输出（JSON，含 24 题逐题明细）
在 `results/`。

## exp2 · 一致率与正确率的相关性

```bash
python experiments/exp2_consistency_correlation.py
```

> **注意**：这个实验的结果**推翻了** README 早期版本"相关性 0.6~0.75"的声称。
> 详见 README 的「实验验证」一节。

### 它检验什么

`filter.py` 把"多次采样的一致率"当作教师答案质量的代理，并声称该代理与真实
正确率的相关性在 0.6~0.75。本脚本用已知 gold 的题库实测这个相关系数。

### 设置

- 教师：Qwen3-0.6B，走 mock 通道的本地路径
  （`config.py` 的 `TeacherAPICfg.mock_model_path`）
- 题库：24 题，四类（算术 / 事实 / 单位换算 / 编程关键字），均有唯一 gold
- 温度：`[0.3, 0.6, 0.9, 1.2, 1.3]`，每温度 1 次 → 题内 5 个样本
- 聚簇：`cluster_mode=fuzzy`、`threshold=0.75`，与 `filter.py` 默认一致
- 总计 120 次教师调用，约 90 秒（单卡）

**关于 `enable_thinking=False`**：Qwen3 是思考模型，默认会先生成几百 token 的
` thinking` 块再给答案。若预算不够（如 64 token）会只输出被截断的推理过程，
最终答案根本没生成，导致准确率恒为 0。脚本显式关掉 thinking，单次生成从
数秒降到约 1.3 秒。

### 三种「正确」口径

| 口径 | 判定 |
|---|---|
| `correct_exact` | 归一化后完全相等，或答案以 gold 结尾 |
| `correct_f1` | 字符级 token F1 ≥ 阈值，或 gold 被答案包含 |
| `correct_loose` | 宽松包含判定 |

需要三种是因为教师习惯输出完整算式（`144 ÷ 12 = 12`）、加粗标记、下标字符
（`H₂O`）。`correct_exact` 因此系统性偏低（0.375），不代表质量差。

### 关键结论

1. **主结论（负面）**：三种口径的 Spearman 均为 **+0.11 ~ +0.27**，
   95% bootstrap CI **全部跨零**。原声称的 0.6~0.75 未复现。
2. **小样本不稳**：同一脚本取前 5 题时 Spearman = **+0.745**（正好落在原区间），
   扩到 24 题后坍缩到 **+0.269**。原数值极可能是小样本噪声。
3. **分桶**：仅有"agreement ≥ 0.8"这一档有效（acc 0.778），
   0.6~0.8 与 0.4~0.6 两档准确率打平（均 0.5），说明阈值取 0.6 没有区分力。
4. **反例**：存在 `agreement = 1.00` 但答案错误的样本（DNA 全称答成 "DNA"），
   直接验证了"一致性 ≠ 正确"。

### 已知局限

n=24 偏小，CI 宽度达 ±0.4；单一教师且仅 0.6B；每温度只采样 1 次。要得到可信
数值至少需要数百题、多教师（含强模型）、每温度多次重复。脚本的 `--limit`
参数可以快速试跑，但**不要用小样本结果做结论**——这正是本实验的核心教训。

### 输出

`results/exp2_consistency_correlation.json`，含逐题明细（问题、gold、教师答案、
agreement、聚簇数、三种判定）与汇总统计，可直接复核每一题。
